Claude Youtube Connector

Privacy policy

Last updated: 2 October 2026.

Purpose and information accessed

This personal application prepares and publishes rain ambience videos for the Calming Rain Sounds channel. It uses the YouTube Application Programming Interface to confirm the authorized channel's identifier and name, upload videos and thumbnails, and read processing and visibility information for its uploads. It requests YouTube upload and read-only permissions.

How information is used

Channel information confirms that uploads go to the intended channel. Upload information supports processing checks, duplicate prevention and recovery. Google user data is not sold or used for advertising. Access is limited to the application's publishing functions.

Storage and sharing

Authorization credentials are stored as encrypted GitHub repository secrets. Publishing records, source metadata and diagnostics are stored in the project repository and GitHub Actions artifacts. The code repository and upload-history branch are public: video identifiers, titles, links and publishing records may be publicly visible, including links to unlisted videos. Source-video bundles are stored in a separate private repository.

Google processes authorization requests and uploaded content. GitHub hosts the workflow, credentials and publishing records. Public videos, thumbnails, titles and descriptions are visible on YouTube. The application does not send Google account data to its stock-media providers.

Retention

Debug artifacts currently expire after 14 days and preview artifacts after 3 days. Upload history is retained to prevent duplicates and support recovery. Authorization credentials are retained until replaced or removed by the repository administrator.

Revocation and deletion

The owner can stop scheduled workflows and revoke access through their Google account connections. Revocation prevents further authorized requests but does not delete existing YouTube videos or GitHub records. The channel owner can manage videos in YouTube Studio; the repository administrator can remove credentials, artifacts and publishing records. Publishing should be stopped and upload history reconciled before deleting records, to avoid accidental duplicate uploads.

Contact and policy changes

Contact the maintainer through the project repository. Changes to the application's handling of data must be reflected in this policy before they are applied.

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
